# Qihanyan.github.io

Personal homepage of Fangjie Gao, built with [Hexo](https://hexo.io) and a small custom theme (`themes/folio`).

- **Edit content:** `source/_data/resume.yml` (all homepage text lives here)
- **Resume PDF:** `source/Fangjie_Gao_Resume.pdf`
- **Write a post (optional):** `npx hexo new "Post title"`; posts appear on the homepage under *Writing* and at `/blog/`
- **Preview locally:** `npm install && npx hexo server`, then open http://localhost:4000
- **Deploy:** push to `main`; `.github/workflows/pages.yml` builds and publishes to GitHub Pages
